# Markdown Cheat Sheet

This version shows each element with **its raw Markdown** immediately followed by its **rendered preview**.

---

## Heading
**Raw Markdown:**
```markdown
# H1
## H2
### H3
```
**Preview:**
# H1
## H2
### H3

---

## Bold
**Raw Markdown:**
```markdown
**bold text**
```
**Preview:**
**bold text**

---

## Italic
**Raw Markdown:**
```markdown

```
**Preview:**
*italicized text*

## Subscript / Superscript
**Raw Markdown:**
```markdown
H~2~O
X^2^
H<sub>2</sub>O
X<sup>2</sup>
```
**Preview:**
H~2~O  
X^2^  
H<sub>2</sub>O  
X<sup>2</sup>
